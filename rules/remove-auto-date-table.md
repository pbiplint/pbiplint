# Remove auto-date table

## What it checks

Calculated tables generated by Auto date/time (names starting with DateTableTemplate_ or LocalDateTable_).

## Why it matters

Avoid using auto-date tables. Make sure to turn off auto-date table in the settings in Power BI Desktop. This will save memory resources.

## How to fix it

Turn off Auto date/time under Options, Data Load, and use a real date table.
