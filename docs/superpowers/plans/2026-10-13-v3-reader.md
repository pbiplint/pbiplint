# v3 Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pull request 2 of v3 ([#78](https://github.com/pbiplint/pbiplint/issues/78)): pbiplint reads every M expression in a model with Microsoft's parser. Each finding can name its TMDL line and column. M that does not parse is a `PARSE_ISSUE`. The name-resolution helper is ready for the rules. No rule is added.

**Architecture:** `lint()` becomes async first, with no parser yet, so the suite stays green before anything else moves. Then the parser arrives behind one shared build module that every bundler uses. After that come the model's two new readings, the column in every output, the M reader with its index, `PARSE_ISSUE` for M, and the parse-time guards. A second part adds the AST helpers and the resolver the rules will use.

**Tech Stack:** TypeScript (core, CLI, site), `@microsoft/powerquery-parser` 2.0.0, esbuild 0.28, Vite 8, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-pbiplint-v3-power-query-layer-design.md`, sections 3 to 8, 11.4 to 11.7, and 12. Read sections 3 to 8 before starting.

## Where this plan reads the spec's wording narrowly

- **Spec 11.6 puts two checks in `check:pack`:** the exact pin, and no non-English template in the CLI's packed bundle. `check:pack` reads only the pack's file list, so the pin is a unit test (`m-parse.test.ts`). The CLI check goes in `check-network.mjs`, the one check that already reads the built bundle. Both run on every change, as the spec intends.
- **Spec 11.5 holds the browser guard to the 300-visual report's two seconds "if the plan's measurement ... shows room".** Node parses the guard model in about 0.7 s, and three browsers on CI runners give no room to spare at two seconds. So both guards use five seconds, enough to catch a parser that has turned quadratic.
- **The prototype of October 13, 2026 found that Vite never offers a JSON file to a plugin's `load` hook.** The Vite plugin therefore redirects the locale templates in `resolveId`, a mechanism spec 3.2 leaves open.

## Review Focus

- **A test that forgets to `await` `lint()`.** It reads `.findings` off a Promise. `npm run typecheck` catches it, since `tsconfig.test.json` covers every test, so Task 1 runs the typecheck before it commits.
- **The Vite build silently shipping all 42 languages.** In the prototype of October 13, 2026, a `load` hook never ran for the locale templates, because Vite's bundler loads JSON itself. The fix redirects them in `resolveId`. Task 2 proves it on the built site with the German probe.
- **A column that points one character off.** Task 5's tests pin the column for each of the three storage styles: inline, block, and fence. A tab-indented line and a space-indented one each get a pinned case.
- **A model whose M is empty or does not parse.** Empty M is skipped silently. M that fails to parse becomes one `PARSE_ISSUE`, and a parse error never throws out of `lint()`. Task 5 and Task 6 pin both.
- **The refresh policy counted twice.** A `sourceExpression` equal to its table's partition, whitespace aside, is not read (spec 5.1). Task 5 pins both the equal and the different case.

```ts
import { DefaultSettings, TaskUtils, type Language, type Parser } from "@microsoft/powerquery-parser";

/** A place in M text, both 0-based: the line, and the UTF-16 code unit in that line. */
export interface MPosition {
  lineNumber: number;
  lineCodeUnit: number;
}

/** The parser's reading of one M expression: its tree, or why it has none and where. */
export type MParse =
  | { ok: true; ast: Language.Ast.TNode; nodeIdMapCollection: Parser.NodeIdMap.Collection }
  | { ok: false; message: string; position?: MPosition };

/**
 * The places a parser error can carry: the token an expected-token error found, the start of a
 * sequence or of tokens left over, or a lex error's grapheme position. Each has lineNumber and
 * lineCodeUnit, 0-based.
 */
interface ErrorWithPosition {
  foundToken?: { token: { positionStart: MPosition } };
  positionStart?: MPosition;
  graphemePosition?: MPosition;
}

/**
 * Parses one M expression with Microsoft's parser and its default settings, whose locale is en-US,
 * so every message is English. Never throws: an error in the parser itself is reported like a
 * parse error, with no position.
 */
export async function parseM(text: string): Promise<MParse> {
  let task;
  try {
    task = await TaskUtils.tryLexParse(DefaultSettings, text);
  } catch (e) {
    return { ok: false, message: e instanceof Error ? e.message : String(e) };
  }
  if (TaskUtils.isParseStageOk(task))
    return { ok: true, ast: task.ast, nodeIdMapCollection: task.nodeIdMapCollection };
  const error = (task as { error?: { message?: string; innerError?: ErrorWithPosition } }).error;
  const inner = error?.innerError;
  const at = inner?.foundToken?.token.positionStart ?? inner?.positionStart ?? inner?.graphemePosition;
  return {
    ok: false,
    message: error?.message ?? "the parser gave no reason",
    ...(at ? { position: { lineNumber: at.lineNumber, lineCodeUnit: at.lineCodeUnit } } : {}),
  };
}
```

```js
// How every bundler that ships the core treats Microsoft's M parser (v3 spec, section 3.2):
// - English only: each localization/templates/template.<locale>.json loads as `{}`, so the
//   bundle carries one language of messages, the one pbiplint asks for, instead of 42.
//   template.json (English) has no locale in its name and is untouched.
// - performance-now resolves to a one-line module on the platform's own `performance`, so the
//   bundle holds no `process.` reference for check:browser to refuse.
// One module, so check:browser, the site's Vite build, and the CLI's esbuild build cannot drift.
// It lives outside src, so it never reaches the browser or the npm package's dist.
import { dirname, resolve } from "node:path";

/** A locale template the parser requires: `template.de-DE.json`, never `template.json`. */
export const LOCALE_TEMPLATE = /[\\/]localization[\\/]templates[\\/]template\.[A-Za-z-]+\.json$/;
/** What a locale template becomes. */
export const EMPTY_TEMPLATE = "{}";
/** The module performance-now becomes. */
export const PERFORMANCE_NOW = "module.exports = () => performance.now();";
/** A word only the German template holds, which a bundle that applied the alias lacks. */
export const GERMAN_PROBE = "Erwartet";

const STUB = "pbiplint-performance-now";
const EMPTY_ID = "pbiplint-empty-locale.json";

/** The esbuild plugin: check:browser and the CLI's build. */
export const mParserEsbuild = {
  name: "pbiplint-m-parser",
  setup(build) {
    build.onLoad({ filter: LOCALE_TEMPLATE }, () => ({ contents: EMPTY_TEMPLATE, loader: "json" }));
    build.onResolve({ filter: /^performance-now$/ }, () => ({ path: STUB, namespace: STUB }));
    build.onLoad({ filter: /.*/, namespace: STUB }, () => ({
      contents: PERFORMANCE_NOW,
      loader: "js",
    }));
  },
};

/**
 * The Vite plugin: the site's build. Vite's bundler loads JSON files itself and never offers a
 * locale template to a plugin's load hook, so the template is redirected where it is resolved.
 */
export const mParserVite = () => ({
  name: "pbiplint-m-parser",
  enforce: "pre",
  resolveId(source, importer) {
    if (source === "performance-now") return `\0${STUB}`;
    if (importer && source.startsWith(".") && LOCALE_TEMPLATE.test(resolve(dirname(importer), source)))
      return `\0${EMPTY_ID}`;
    return null;
  },
  load(id) {
    if (id === `\0${STUB}`) return PERFORMANCE_NOW;
    if (id === `\0${EMPTY_ID}`) return EMPTY_TEMPLATE;
    return null;
  },
});
```

```ts
import type { LintFile } from "../engine/lint.js";
import type { Model, NamedExpression, Partition, SourceLocation, Table } from "../model/types.js";
import type { TmdlNode } from "../tmdl/types.js";
import { parseM, type MPosition } from "./parse.js";
import type { MIndex, MParseIssue, MQuery } from "./types.js";

/** Text with every run of whitespace as one space, to compare M as Desktop rewrites it. */
const squash = (s: string): string => s.replace(/\s+/g, " ").trim();

/** The node whose value is a partition's M: its `source =` expression. */
const partitionSource = (p: Partition): TmdlNode | undefined =>
  p.node?.children.find((c) => c.kind === "expr" && c.type === "source");

/** The node whose value is a shared expression's M: the declaration, or its `expression =` line. */
const expressionSource = (x: NamedExpression): TmdlNode | undefined =>
  x.node?.value !== undefined
    ? x.node
    : x.node?.children.find((c) => c.kind === "expr" && c.type === "expression");

/** The node whose value is a refresh policy's M: its `sourceExpression =` line. */
const policySource = (t: Table): TmdlNode | undefined =>
  t.refreshPolicy?.node?.children.find((c) => c.kind === "expr" && c.type === "sourceexpression");

/** Each file's lines, split as parseTmdl splits them, read only when a location needs one. */
function lineReader(files: LintFile[]): (file: string, line: number) => string {
  const texts = new Map(files.map((f) => [f.path, f.text]));
  const cache = new Map<string, string[]>();
  return (file, line) => {
    let lines = cache.get(file);
    if (!lines) {
      const text = texts.get(file) ?? "";
      const body = text.charCodeAt(0) === 0xfeff ? text.slice(1) : text;
      lines = body.replace(/\r\n?/g, "\n").split("\n");
      cache.set(file, lines);
    }
    return lines[line - 1] ?? "";
  };
}

/** The index of a model with no M, and of a lint with no model. */
export function emptyMIndex(): MIndex {
  return {
    queries: [],
    issues: [],
    locate: (q, at) => ({ file: q.file, line: q.valueLine + at.lineNumber }),
  };
}

/**
 * Reads every M expression in the model with Microsoft's parser (v3 spec, section 5): each M
 * partition's source, each shared expression, and each refresh policy's source expression that is
 * not, whitespace aside, one of its table's M partitions, which Desktop writes to both. Empty M is
 * skipped. M that does not parse is an issue at the TMDL line and column the parser stopped at,
 * and its query keeps no tree.
 */
export async function readM(model: Model, files: LintFile[]): Promise<MIndex> {
  const lineAt = lineReader(files);
  const mLines = new WeakMap<MQuery, string[]>();
  const locate = (q: MQuery, at: MPosition): SourceLocation => {
    let lines = mLines.get(q);
    if (!lines) mLines.set(q, (lines = q.text.split("\n")));
    const line = q.valueLine + at.lineNumber;
    // Every M line that is not blank ends where its TMDL line ends (v3 spec, section 6.1).
    const offset = lineAt(q.file, line).trimEnd().length - (lines[at.lineNumber] ?? "").trimEnd().length;
    return { file: q.file, line, column: Math.max(0, offset) + at.lineCodeUnit + 1 };
  };
  const queries: MQuery[] = [];
  const add = (kind: MQuery["kind"], name: string, owner: MQuery["owner"], node: TmdlNode | undefined) => {
    const text = node?.value ?? "";
    if (!node || node.valueLine === undefined || text.trim() === "") return;
    queries.push({ kind, name, owner, text, file: node.file, valueLine: node.valueLine });
  };
  for (const t of model.tables) {
    const mParts = t.partitions.filter((p) => p.sourceType === "m");
    for (const p of mParts) add("partition", t.name, p, partitionSource(p));
    const policy = policySource(t);
    if (policy && !mParts.some((p) => squash(p.source ?? "") === squash(policy.value ?? "")))
      add("refreshPolicy", t.name, t, policy);
  }
  for (const x of model.expressions) add("expression", x.name, x, expressionSource(x));

  const issues: MParseIssue[] = [];
  for (const q of queries) {
    const parsed = await parseM(q.text);
    if (parsed.ok) {
      q.ast = parsed.ast;
      q.nodeIdMapCollection = parsed.nodeIdMapCollection;
      continue;
    }
    const at = locate(q, parsed.position ?? { lineNumber: 0, lineCodeUnit: 0 });
    issues.push({
      file: at.file,
      line: at.line,
      column: at.column!,
      // Cut as a JSON issue's line is (readJson): a generated partition can hold lines of megabytes.
      text: lineAt(at.file, at.line).trim().slice(0, 120),
      reason: `M could not be parsed: ${parsed.message}`,
    });
  }
  return { queries, issues, locate };
}
```

```js
#!/usr/bin/env node
// Usage: node scripts/make-big-model.mjs <out>
// Writes <out>/big-model.SemanticModel, a model whose M is as heavy to parse as the corpus's slowest
// (v3 spec, section 11.5): 8 partitions of 6,250 #table rows each, about 400,000 tokens. The
// browser suite and the Node guard hold its lint to a budget. Nothing it writes is committed
// (.gitignore lists tests/generated/, where the suite puts it).
import { existsSync, mkdirSync, readdirSync, realpathSync, rmSync, writeFileSync } from "node:fs";
import { join, resolve } from "node:path";
import { pathToFileURL } from "node:url";

export const PARTITIONS = 8;
export const ROWS = 6250;
const FOLDER = "big-model.SemanticModel";

/** One partition's table, its rows written one to a line as Desktop writes long M. */
function table(n) {
  const rows = Array.from(
    { length: ROWS },
    (_, i) => `\t\t\t\t\t\t{${i + 1}, "Row ${i + 1}", ${(i % 97) + 0.5}}${i + 1 < ROWS ? "," : ""}`,
  );
  return [
    `table 'Data ${n}'`,
    "\tcolumn Id",
    "\t\tdataType: int64",
    "\t\tformatString: 0",
    "\t\tsummarizeBy: none",
    "\t\tsourceColumn: Id",
    "",
    `\tpartition 'Data ${n}' = m`,
    "\t\tmode: import",
    "\t\tsource =",
    "\t\t\t\tlet",
    "\t\t\t\t    Source = #table(type table [Id = number, Name = text, Amount = number], {",
    ...rows,
    "\t\t\t\t    })",
    "\t\t\t\tin",
    "\t\t\t\t    Source",
    "",
  ].join("\n");
}

/** The model's files, as lint reads them. */
export function bigModelFiles() {
  return [
    { path: "definition/database.tmdl", text: "database\n\tcompatibilityLevel: 1702\n" },
    { path: "definition/model.tmdl", text: "model Model\n\tculture: en-US\n" },
    ...Array.from({ length: PARTITIONS }, (_, i) => ({
      path: `definition/tables/Data ${i + 1}.tmdl`,
      text: table(i + 1),
    })),
  ];
}

/** Writes the model under `out`, replacing an earlier copy, and returns its partition count. */
export function makeBigModel(out) {
  const root = join(resolve(out), FOLDER);
  // Only an earlier copy is ever replaced, so a slip of the argument cannot delete a real folder.
  if (existsSync(out) && readdirSync(out).some((name) => name !== FOLDER))
    throw new Error(`${out} holds more than an earlier big model; not writing into it`);
  rmSync(root, { recursive: true, force: true });
  for (const f of bigModelFiles()) {
    const path = join(root, f.path);
    mkdirSync(join(path, ".."), { recursive: true });
    writeFileSync(path, f.text);
  }
  return PARTITIONS;
}

function main() {
  const out = process.argv[2];
  if (!out) {
    console.error("usage: node scripts/make-big-model.mjs <out>");
    process.exit(2);
  }
  console.log(`wrote ${makeBigModel(out)} M partitions to ${join(out, FOLDER)}`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(realpathSync(process.argv[1])).href)
  main();
```

```ts
// Usage, from the repository root:
//   npx tsx .superpowers/sdd/2026-10-13-v3-reader/corpus-diff.mts <base core dir> <corpus dir>
import { readdirSync, readFileSync } from "node:fs";
import { join, relative } from "node:path";

const [baseDir, corpus] = process.argv.slice(2);
const base = await import(join(baseDir!, "packages/core/src/index.ts"));
const head = await import(join(process.cwd(), "packages/core/src/index.ts"));

const roots: string[] = [];
const walk = (d: string) => {
  for (const e of readdirSync(d, { withFileTypes: true })) {
    if (!e.isDirectory() || e.name === ".git" || e.name === "node_modules") continue;
    const p = join(d, e.name);
    if (e.name === "definition" && /\.(SemanticModel|Dataset)$/.test(d)) roots.push(p);
    else walk(p);
  }
};
walk(corpus!);
const tmdls = (d: string): string[] =>
  readdirSync(d, { withFileTypes: true }).flatMap((e) =>
    e.isDirectory() ? tmdls(join(d, e.name)) : e.name.endsWith(".tmdl") ? [join(d, e.name)] : [],
  );
const key = (f: { ruleId: string; objectType: string; objectName: string; location?: { file: string; line: number }; detail?: string }) =>
  JSON.stringify([f.ruleId, f.objectType, f.objectName, f.location?.file ?? "", f.location?.line ?? 0, f.detail ?? ""]);

const added = new Map<string, string[]>();
const removed = new Map<string, string[]>();
let models = 0;
for (const root of roots) {
  const files = tmdls(root).map((f) => ({ path: relative(root, f).split("\\").join("/"), text: readFileSync(f, "utf8") }));
  let before, after;
  try {
    before = await base.lint(files, { config: { failOn: "none" } });
    after = await head.lint(files, { config: { failOn: "none" } });
  } catch (e) {
    console.log(`ERROR ${relative(corpus!, root)}: ${e instanceof Error ? e.message : e}`);
    continue;
  }
  models++;
  const a = new Set(before.findings.map(key));
  const b = new Set(after.findings.map(key));
  for (const k of b) if (!a.has(k)) (added.get(JSON.parse(k)[0]) ?? added.set(JSON.parse(k)[0], []).get(JSON.parse(k)[0])!).push(`${relative(corpus!, root)} ${k}`);
  for (const k of a) if (!b.has(k)) (removed.get(JSON.parse(k)[0]) ?? removed.set(JSON.parse(k)[0], []).get(JSON.parse(k)[0])!).push(`${relative(corpus!, root)} ${k}`);
}
console.log(`${models} models linted`);
for (const [rule, list] of added) console.log(`+${list.length} ${rule}\n  ${list.slice(0, 5).join("\n  ")}`);
for (const [rule, list] of removed) console.log(`-${list.length} ${rule}\n  ${list.slice(0, 5).join("\n  ")}`);
```

```ts
import { Language } from "@microsoft/powerquery-parser";
import type { MQuery } from "./types.js";

type Node = Language.Ast.TNode;
const Kind = Language.Ast.NodeKind;

/** An identifier as M compares it: `#"Sorted Rows"` is `Sorted Rows`, with doubled quotes undone. */
export const identifierName = (literal: string): string =>
  literal.startsWith('#"') ? literal.slice(2, -1).replace(/""/g, '"') : literal;

/** A text literal's value, without its quotes and with doubled quotes undone; undefined for any other node. */
export function textValue(node: Node | undefined): string | undefined {
  return node?.kind === Kind.LiteralExpression && node.literalKind === Language.Ast.LiteralKind.Text
    ? node.literal.slice(1, -1).replace(/""/g, '"')
    : undefined;
}

/** A node of a parsed query, by id. */
export const nodeOf = (q: MQuery, id: number): Node | undefined =>
  q.nodeIdMapCollection?.astNodeById.get(id);

/** A node's parent in its query's tree; undefined at the root. */
export function parentOf(q: MQuery, node: Node): Node | undefined {
  const id = q.nodeIdMapCollection?.parentIdById.get(node.id);
  return id === undefined ? undefined : nodeOf(q, id);
}

/** A value with any `meta` record and parentheses taken off, as a parameter's literal is written. */
export function unwrap(node: Node): Node {
  let n = node;
  for (;;) {
    if (n.kind === Kind.MetadataExpression) n = n.left;
    else if (n.kind === Kind.ParenthesizedExpression) n = n.content;
    else return n;
  }
}

/** One invocation of a function named by an identifier: `Web.Contents(...)`, `@f(...)`, `#"My Fn"(...)`. */
export interface MCall {
  name: string;
  args: Node[];
  /** The whole call, from its name to its closing parenthesis. */
  node: Node;
}

/** Every invocation in a query whose function is named by an identifier, in text order. */
export function calls(q: MQuery): MCall[] {
  const ids = q.nodeIdMapCollection?.idsByNodeKind.get(Kind.RecursivePrimaryExpression) ?? new Set<number>();
  const out: MCall[] = [];
  for (const id of [...ids].sort((a, b) => a - b)) {
    const n = nodeOf(q, id);
    if (n?.kind !== Kind.RecursivePrimaryExpression || n.head.kind !== Kind.IdentifierExpression) continue;
    const first = n.recursiveExpressions.elements[0];
    if (first?.kind !== Kind.InvokeExpression) continue;
    out.push({
      name: identifierName(n.head.identifier.literal),
      args: first.content.elements.map((csv) => csv.node),
      node: n,
    });
  }
  return out;
}

/**
 * The name of the outermost `let` step that holds a node, as Applied steps lists it, or undefined
 * when the node is in no step: the query has no `let`, or the node is in its `in` expression.
 */
export function stepOf(q: MQuery, node: Node): string | undefined {
  if (!q.ast) return undefined;
  const root = unwrap(q.ast);
  if (root.kind !== Kind.LetExpression) return undefined;
  let child: Node | undefined = node;
  let parent = parentOf(q, node);
  while (parent) {
    if (child.kind === Kind.IdentifierPairedExpression) {
      // The pair sits in a Csv inside the let's variable list: three steps up is the let.
      const csv = parent;
      const list = parentOf(q, csv);
      const owner = list && parentOf(q, list);
      if (owner?.id === root.id) return identifierName(child.key.literal);
    }
    child = parent;
    parent = parentOf(q, parent);
  }
  return undefined;
}
```

```ts
import { Language } from "@microsoft/powerquery-parser";
import { identifierName, nodeOf, parentOf, unwrap } from "./ast.js";
import type { MIndex, MQuery } from "./types.js";

type Node = Language.Ast.TNode;
const Kind = Language.Ast.NodeKind;

/** Where a name in M gets its value (v3 spec, section 8). */
export type Resolution =
  | { kind: "row" }
  | { kind: "parameter"; node: Node }
  | { kind: "value"; node: Node }
  | { kind: "modelParameter"; query: MQuery; value: Node }
  | { kind: "query"; query: MQuery }
  | { kind: "library" }
  | { kind: "unknown" };

/**
 * A shared expression's value when it is a Power Query parameter, `<value> meta [IsParameterQuery =
 * true, ...]`; undefined for any other query.
 */
export function isModelParameter(q: MQuery): Node | undefined {
  if (q.kind !== "expression" || q.ast?.kind !== Kind.MetadataExpression) return undefined;
  const meta = unwrap(q.ast.right);
  if (meta.kind !== Kind.RecordExpression && meta.kind !== Kind.RecordLiteral) return undefined;
  const flag = meta.content.elements.find((csv) => identifierName(csv.node.key.literal) === "IsParameterQuery");
  const value = flag?.node.value;
  return value?.kind === Kind.LiteralExpression && value.literal === "true" ? q.ast.left : undefined;
}

/** The variables a let binds, the fields a record's other fields see, a function's parameters. */
function bindingIn(scope: Node, name: string): Resolution | undefined {
  if (scope.kind === Kind.LetExpression) {
    const pair = scope.variableList.elements.find((csv) => identifierName(csv.node.key.literal) === name);
    return pair ? { kind: "value", node: pair.node.value } : undefined;
  }
  if (scope.kind === Kind.RecordExpression) {
    const field = scope.content.elements.find((csv) => identifierName(csv.node.key.literal) === name);
    return field ? { kind: "value", node: field.node.value } : undefined;
  }
  if (scope.kind === Kind.FunctionExpression) {
    const param = scope.parameters.content.elements.find((csv) => identifierName(csv.node.name.literal) === name);
    return param ? { kind: "parameter", node: param.node } : undefined;
  }
  if (scope.kind === Kind.EachExpression && name === "_") return { kind: "row" };
  return undefined;
}

/**
 * Where an identifier gets its value: the nearest enclosing `each`, function, `let`, or record that
 * binds it, then the model's parameters, then its other queries by name (shared expressions first,
 * then tables' queries). A name with a `.` is a library function; anything else is unknown. A node
 * that is not an identifier is unknown.
 */
export function resolve(m: MIndex, q: MQuery, node: Node): Resolution {
  if (node.kind !== Kind.IdentifierExpression) return { kind: "unknown" };
  const name = identifierName(node.identifier.literal);
  for (let scope = parentOf(q, node); scope; scope = parentOf(q, scope)) {
    const found = bindingIn(scope, name);
    if (found) return found;
  }
  const shared = m.queries.find((x) => x.kind === "expression" && x.name === name);
  if (shared) {
    const value = isModelParameter(shared);
    return value ? { kind: "modelParameter", query: shared, value } : { kind: "query", query: shared };
  }
  const table = m.queries.find((x) => x.kind !== "expression" && x.name === name && x !== q);
  if (table) return { kind: "query", query: table };
  return name.includes(".") ? { kind: "library" } : { kind: "unknown" };
}

void nodeOf;
```

```ts
/** Where a value comes from, as the data source rule reads it (v3 spec, section 8). */
export type Origin = "static" | "unknown" | "computed" | "row";
/** Worst last: a value is as bad as the worst thing it reaches. */
export const ORIGIN_ORDER: readonly Origin[] = ["static", "unknown", "computed", "row"];
const worst = (origins: Origin[]): Origin =>
  origins.reduce<Origin>((w, o) => (ORIGIN_ORDER.indexOf(o) > ORIGIN_ORDER.indexOf(w) ? o : w), "static");

/** A record or list written in place, whose fields or items are known without reading data. */
const isLiteralContainer = (n: Node): boolean =>
  n.kind === Kind.RecordExpression || n.kind === Kind.RecordLiteral || n.kind === Kind.ListExpression || n.kind === Kind.ListLiteral;

/**
 * Where a value comes from: `static` for literals, model parameters, and what joins or chooses
 * among them; `unknown` for a function's parameter, a name nothing defines, a field or item of a
 * record or list written in place, or a cycle; `computed` for a function call anywhere in it;
 * `row` for `_` or a field or item of anything else. A value is the worst of what it reaches.
 * Each node is followed once, so a cycle reads as unknown.
 */
export function origin(m: MIndex, q: MQuery, node: Node, seen: Set<string> = new Set()): Origin {
  const key = `${q.kind}:${q.name}:${node.id}`;
  if (seen.has(key)) return "unknown";
  seen.add(key);
  switch (node.kind) {
    case Kind.LiteralExpression:
    case Kind.Constant:
      return "static";
    case Kind.IdentifierExpression: {
      const r = resolve(m, q, node);
      if (r.kind === "row") return "row";
      if (r.kind === "value") return origin(m, q, r.node, seen);
      if (r.kind === "modelParameter" || r.kind === "library") return "static";
      if (r.kind === "query") {
        const body = r.query.ast && unwrap(r.query.ast);
        if (!body || body.kind === Kind.FunctionExpression) return "unknown";
        return origin(m, r.query, body, seen);
      }
      return "unknown";
    }
    case Kind.FieldSelector:
    case Kind.FieldProjection:
      return "row";
    case Kind.LetExpression:
      return origin(m, q, node.expression, seen);
    case Kind.FunctionExpression:
    case Kind.EachExpression:
      return "unknown";
    case Kind.RecursivePrimaryExpression: {
      const steps = node.recursiveExpressions.elements;
      const invoke = steps.find((s) => s.kind === Kind.InvokeExpression);
      if (invoke && invoke.kind === Kind.InvokeExpression)
        return worst(["computed", ...invoke.content.elements.map((csv) => origin(m, q, csv.node, seen))]);
      // A field or an item: of a record or list written in place, or a name bound to one, it is known.
      const head = node.head;
      const target = head.kind === Kind.IdentifierExpression ? resolve(m, q, head) : undefined;
      const container = target?.kind === "value" ? unwrap(target.node) : unwrap(head);
      return isLiteralContainer(container) ? "unknown" : "row";
    }
    default: {
      const children = q.nodeIdMapCollection?.childIdsById.get(node.id) ?? [];
      return worst(children.map((id) => nodeOf(q, id)).filter((n): n is Node => n !== undefined).map((n) => origin(m, q, n, seen)));
    }
  }
}
```
